# WTD → XTD (SwiftUI, iOS 16+)

1. In Xcode: File ▸ New ▸ Project ▸ iOS ▸ App (Interface: SwiftUI, Language: Swift).
2. Delete the generated `ContentView.swift` and `<Name>App.swift`.
3. Drag the four files in `Sources/` into the project.
4. Build & run. Tap "Choose .wtd or .zip files", then the share icon on a result to save the .xtd to Files.

`Reference/` holds the Python implementation used to verify the format against your sample
(`python3 wtd2xtd.py in.wtd out.xtd`), plus a small LZX decoder (`lzxd.py`) used for testing.

## Build an IPA with GitHub Actions

Put the contents of this folder at the root of a GitHub repo (`project.yml`, `Sources/`, `.github/`).
Every push, PR or manual run ("Actions" ▸ "Build IPA" ▸ "Run workflow") builds an **unsigned**
`WTD2XTD.ipa` and uploads it as an artifact. Pushing a tag like `v1.0` also attaches it to a release.

The project is generated by XcodeGen from `project.yml` (change the bundle id there).
Unsigned IPAs must be signed before they install: use AltStore / SideStore / Sideloadly with your
Apple ID, or TrollStore.
